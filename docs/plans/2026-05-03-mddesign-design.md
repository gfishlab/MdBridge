# MDBridge 设计文档

## 概述

MDBridge 是一个跨平台（Mac + Windows）桌面 Markdown 编辑器，核心功能是将 MD 文档转换为适配多个媒体平台的格式，通过剪贴板复制供用户粘贴发布。

**不涉及自动发布**，仅做格式转换 + 复制到剪贴板。

## 目标平台

微信公众号、B站专栏、CSDN、抖音/小红书、推特、知乎、掘金

## 技术栈

| 层 | 技术 |
|---|------|
| 框架 | Tauri 2.x |
| 后端 | Rust |
| 前端 | React 18 + TypeScript |
| 编辑器 | @uiw/react-md-editor (基于 CodeMirror 6) |
| MD 解析 | comrak (CommonMark AST) |
| 剪贴板 | arboard (Rust) |
| 自动更新 | tauri-plugin-updater |

## 平台转换引擎

### Trait 接口

```rust
trait PlatformConverter {

    fn convert(&self, ast: &AstNode) -> String;

```

### 平台差异矩阵

| 元素 | 微信公众号 | B站专栏 | CSDN | 抖音/小红书 | 推特 | 知乎 | 掘金 |
|------|-----------|---------|------|------------|------|------|------|
| 标题 | 支持 | 支持 | 支持 | 纯文本 | 纯文本 | 支持 | 支持 |
| 代码块 | 特殊处理 | 支持 | 支持 | 纯文本 | 纯文本 | 支持 | 支持 |
| 表格 | 不支持 | 支持 | 支持 | 不支持 | 不支持 | 支持 | 支持 |
| 图片 | 外链OK | 需内嵌 | 需内嵌 | 需内嵌 | 需内嵌 | 外链OK | 外链OK |
| 链接 | 支持 | 支持 | 支持 | 不支持 | 支持 | 支持 | 支持 |

### 各平台详细转换规则

#### 微信公众号

- **输出格式**：HTML（富文本）
- **标题**：`<h1>` ~ `<h6>`，带内联样式 `font-size` + `font-weight`
- **段落**：`<p>` 带 `line-height: 1.75` 内联样式
- **代码块**：不支持 `<pre><code>`，需转为带背景色的 `<section>` + `<code>` 带内联样式：
  ```html
  <section style="background:#f6f8fa;padding:12px;border-radius:4px;">
    <code style="font-family:Consolas,monospace;font-size:13px;">代码内容</code>
  </section>
  ```
- **行内代码**：`<code>` 带背景色和 padding 内联样式
- **表格**：不支持，降级为带分隔线的文本格式：
  ```
  列1: 值1 | 列2: 值2
  列1: 值3 | 列2: 值4
  ```
- **图片**：外链直接使用，需加 `max-width:100%` 样式
- **链接**：转为带下划线的蓝色文字，微信会自动识别
- **加粗/斜体**：`<strong>` / `<em>` 正常输出
- **列表**：`<ul>/<ol>` + `<li>` 正常输出

#### B站专栏

- **输出格式**：HTML
- **标题**：`<h1>` ~ `<h6>` 正常输出
- **代码块**：`<pre><code>` 正常输出，支持语法高亮（需加 `class="language-xxx"`）
- **表格**：`<table>` 正常输出
- **图片**：不支持外链，需下载后内嵌为 base64 `<img src="data:image/...">`
- **链接**：`<a href>` 正常输出
- **列表**：正常输出

#### CSDN

- **输出格式**：HTML
- **标题**：正常输出
- **代码块**：`<pre><code>` 正常输出，支持语法高亮
- **表格**：`<table>` 正常输出
- **图片**：不支持外链，需内嵌 base64
- **链接**：正常输出
- **列表**：正常输出

#### 抖音/小红书

- **输出格式**：纯文本（不支持 HTML）
- **标题**：转为纯文本，前后加空行
- **段落**：纯文本，段落间换行
- **代码块**：转为纯文本，保留缩进
- **表格**：转为纯文本，列之间用 ` | ` 分隔
- **图片**：不支持外链，需内嵌（但纯文本模式下图片无法显示，需提示用户手动插入）
- **链接**：仅保留 URL 文本
- **加粗/斜体**：移除格式标记，仅保留文本
- **列表**：转为带 `- ` 前缀的纯文本

#### 推特

- **输出格式**：纯文本（推文长度限制 280 字符）
- **标题**：纯文本
- **段落**：纯文本，换行分隔
- **代码块**：纯文本
- **表格**：纯文本，简化格式
- **图片**：不支持内嵌，提示用户手动上传
- **链接**：保留 URL 文本（推特会自动缩短链接）
- **加粗/斜体**：移除格式标记
- **列表**：纯文本，带 `- ` 前缀
- **长度处理**：如超过 280 字符，提示用户内容过长

#### 知乎

- **输出格式**：HTML
- **标题**：正常输出
- **代码块**：`<pre><code>` 正常输出
- **表格**：`<table>` 正常输出
- **图片**：外链直接使用
- **链接**：正常输出
- **列表**：正常输出
- **知乎特殊**：支持 LaTeX 公式（`$...$` 和 `$$...$$`），保持原样

#### 掘金

- **输出格式**：Markdown（掘金原生支持 MD）
- **所有元素**：保持原始 Markdown 语法不变
- **图片**：外链直接使用
- **代码块**：保持原样，支持语法高亮
- **表格**：保持原样
- **特殊**：掘金支持 Markdown 扩展语法（如 `[toc]`），保持原样

## 图片处理

### 工作流

用户写 MD 时通过 PicoGo 上传图片到 GitHub 图床，MD 中保留 GitHub 图片链接。

### 转换策略

- **支持外链的平台**（微信、知乎、掘金）：链接原样保留
- **不支持外链的平台**（B站、CSDN、抖音、小红书、推特）：下载图片 → 内嵌 base64 → 富文本剪贴板

### 缓存策略

| 层面 | 策略 |
|------|------|
| 内存 | 仅在"生成→复制"期间临时持有，操作完成后立即释放 |
| 磁盘缓存 | 图片按 URL hash 存储，同一张图不重复下载 |
| 容量上限 | 默认 500MB，可配置 |
| 淘汰策略 | LRU |
| 手动清理 | 设置页提供"清除图片缓存"按钮 |

## 系统托盘

```
托盘图标右键菜单：

├── 快速发布（最近使用的平台）
```

- 全局快捷键呼出（默认 `Cmd/Ctrl+Shift+M`）

## 自动更新

- 使用 tauri-plugin-updater
- 应用启动时后台检查更新
- 有新版本时托盘图标显示角标
- 用户点击更新 → 自动下载 → 自动替换 → 提示重启
- 更新源：GitHub Releases

```
┌──────────────────────────────────────────────────────────┐
```

三种视图模式：

- ↔️ 并排模式：左右分屏（默认）

### 文件管理

- 支持打开单个 .md 文件
- 支持打开文件夹，左侧显示文件树
- 文件菜单：打开文件、打开文件夹、最近文件、保存、另存为
- 文件树可折叠

| `Cmd/Ctrl+Shift+M` | 呼出/隐藏主窗口 |

## 设置页

- 图片缓存大小配置（默认 500MB）
- 清除图片缓存
- 默认发布平台
- 快捷键配置
- 启动时检查更新开关

## 错误处理

- 图片下载失败：降级保留原链接 + 状态栏提示
- 超大图片（>5MB）：跳过内嵌 + 提示用户手动处理
- 网络异常：提示用户检查网络
- 转换失败：提示具体错误信息
