# MDBridge 设计文档

## 概述

MDBridge 是一个跨平台（Mac + Windows）桌面 Markdown 编辑器，核心功能是将 MD 文档转换为适配多个媒体平台的格式，通过剪贴板复制供用户粘贴发布。

**不涉及自动发布**，仅做格式转换 + 复制到剪贴板。

## 目标平台

微信公众号、B站专栏、CSDN、抖音/小红书、推特、知乎、掘金

## 技术栈

| 层 | 技术 |
|---|------|
| 框架 | Tauri 2.x |
| 后端 | Rust |
| 前端 | React 18 + TypeScript |
| 编辑器 | @uiw/react-md-editor (基于 CodeMirror 6) |
| MD 解析 | comrak (CommonMark AST) |
| 剪贴板 | arboard (Rust) |
| 自动更新 | tauri-plugin-updater |

## 图片处理

### 工作流

用户写 MD 时通过 PicoGo 上传图片到 GitHub 图床，MD 中保留 GitHub 图片链接。

### 转换策略

- **支持外链的平台**（微信、知乎、掘金）：链接原样保留
- **不支持外链的平台**（B站、CSDN、抖音、小红书、推特）：下载图片 → 内嵌 base64 → 富文本剪贴板

### 缓存策略

| 层面 | 策略 |
|------|------|
| 内存 | 仅在"生成→复制"期间临时持有，操作完成后立即释放 |
| 磁盘缓存 | 图片按 URL hash 存储，同一张图不重复下载 |
| 容量上限 | 默认 500MB，可配置 |
| 淘汰策略 | LRU |
| 手动清理 | 设置页提供"清除图片缓存"按钮 |

## 系统托盘

```
托盘图标右键菜单：
├── 打开主窗口
├── 快速发布（最近使用的平台）
├── 设置
└── 退出
```

- 关闭窗口时最小化到托盘，不退出应用
- 全局快捷键呼出（默认 `Cmd/Ctrl+Shift+M`）

## 自动更新

- 使用 tauri-plugin-updater
- 应用启动时后台检查更新
- 有新版本时托盘图标显示角标
- 用户点击更新 → 自动下载 → 自动替换 → 提示重启
- 更新源：GitHub Releases

## UI 布局

### 顶部工具栏

```
┌──────────────────────────────────────────────────────────┐
│  MDBridge   [文件 ▾][发布 ▾]           [✏️][↔️][👁] ─ □ ×│
```

- 左侧：应用名、文件菜单、发布菜单
- 右侧：视图切换图标、窗口控制按钮

### 编辑/预览

三种视图模式：
- ✏️ 编辑模式：仅编辑区，全宽
- ↔️ 并排模式：左右分屏（默认）
- 👁 预览模式：仅预览区，全宽

### 文件管理

- 支持打开单个 .md 文件
- 支持打开文件夹，左侧显示文件树
- 文件菜单：打开文件、打开文件夹、最近文件、保存、另存为
- 文件树可折叠

### 发布菜单

```
[发布 ▾] → 微信公众号
              B站专栏
              CSDN
              抖音/小红书
              推特
              知乎
              掘金
```

选择平台 → 转换 → 复制到剪贴板 → 底部状态栏提示"已复制"

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Cmd/Ctrl+S` | 保存 |
| `Cmd/Ctrl+Shift+P` | 快速发布（上次使用的平台） |
| `Cmd/Ctrl+Shift+M` | 呼出/隐藏主窗口 |
| `Cmd/Ctrl+1/2/3` | 切换编辑/并排/预览视图 |

## 设置页

- 图片缓存大小配置（默认 500MB）
- 清除图片缓存
- 默认发布平台
- 快捷键配置
- 启动时检查更新开关

## 错误处理

- 图片下载失败：降级保留原链接 + 状态栏提示
- 超大图片（>5MB）：跳过内嵌 + 提示用户手动处理
- 网络异常：提示用户检查网络
- 转换失败：提示具体错误信息
