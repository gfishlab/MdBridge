# 设置菜单收敛设计

## 目标

收敛 MDBridge 顶部工具栏的重复入口。移除“视图”菜单，将应用偏好统一保留在“设置”中，同时保留文件树的显示与隐藏能力。

## 范围

- 删除顶部“视图”按钮及其弹出菜单。
- 删除仅用于“视图”菜单的 React 状态、引用和点击外部关闭逻辑。
- 在“文件”菜单中新增“显示文件树”或“隐藏文件树”命令；未打开文件夹时禁用该命令。
- 保留“设置”作为主题、文字样式、默认发布平台、图片缓存大小、清理缓存、手动检查更新和启动时检查更新的唯一入口。

## 交互

打开文件夹后，文件树照常显示。用户可从“文件”菜单切换文件树的显示状态。打开设置不会改变文件树状态，也不会影响既有配置的读取、保存或跨窗口同步。

## 实现边界

只修改前端菜单结构和相关测试。设置组件与 Rust 配置、缓存、更新命令均保持现状，不引入新的配置字段或后端接口。

## 验证

- 工具栏不再显示“视图”，仍显示“文件 / 编辑 / 发布 / 设置 / 帮助”。
- 文件菜单可切换已打开文件夹的文件树；未打开文件夹时命令不可用。
- 设置仍可保存主题及文字样式。
- 运行 `npm test -- --run`、`npm run build` 和 `git diff --check`。
