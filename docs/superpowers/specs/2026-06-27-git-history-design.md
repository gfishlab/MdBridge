# MdBridge Git 历史版本设计

## 目标

v2.0.0 为 MdBridge 增加本地 Git 文档版本历史能力，让个人和团队可以基于共享 Git 仓库追踪 Markdown 文档的修改来源、查看差异、恢复历史版本，并完成基础提交与同步。

## 产品边界

- MdBridge 仍然是本地桌面客户端。
- Git 是版本历史和异步团队协作底座。
- 不引入 MdBridge 自有账号、服务端、房间状态、权限系统或实时多人编辑。
- 不做完整 Git 客户端，不处理 merge/rebase/复杂冲突编辑。

## 第一版能力

- 底部状态栏显示版本入口、当前分支和修改数量。
- 左侧版本面板展示仓库状态、分支列表、当前文档提交历史。
- 提交历史展示提交说明、短 hash、提交者名称、邮箱和提交时间。
- 选择提交后显示当前文档 diff。
- 支持将当前文档恢复到选中历史版本。
- 支持提交当前文档。
- 支持基础拉取和推送，复用用户本机 Git 凭据。

## 架构

- Rust 后端新增 `git_integration` 模块，所有 Git CLI 调用都集中在该模块。
- Tauri command 只暴露结构化接口给前端，不让 React 直接解析 Git 输出。
- React 新增 `GitPanel` 组件，负责版本面板 UI、历史加载、diff 加载、恢复、提交、同步操作。
- `App.tsx` 只负责状态栏入口、面板开关、保存前置动作，以及恢复版本后同步当前标签内容。

## 错误处理

- 未安装 Git、当前路径不在 Git 仓库中、无远程凭据、pull/push 失败时，前端显示错误信息。
- Git 命令设置 `GIT_TERMINAL_PROMPT=0`，避免桌面应用在缺少凭据时阻塞。
- 恢复历史版本前要求用户确认，因为该操作会覆盖当前工作区文件。

## 验证

- Rust 单元测试覆盖 Git status、branch、log 输出解析。
- React 组件测试覆盖版本面板加载、diff 展示、恢复历史版本、提交当前文档。
- App 集成测试覆盖从底部状态栏打开版本面板并显示当前文档历史。
